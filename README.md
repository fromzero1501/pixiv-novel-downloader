# Pixiv小说下载管理器

Windows 本地作品管理软件，用于按作者管理 Pixiv 小说预览版与完整版文件，记录购买状态、封面、标签、系列和收藏。

## 功能

- 作者库、所有作品与系列作品浏览
- 导入作品名称、关联预览版/完整版文件和封面
- 基于相似度的文件匹配、批量操作、标签与收藏管理
- 从 Pixiv 作者主页同步小说正文、封面、投稿日期、标签和系列信息
- 同步按原始投稿时间筛选，支持增量同步、进度、终止和抓取限速
- 便携式 SQLite 数据库，数据保存在程序目录旁的 `data` 文件夹

## 操作指南

### 1. 首次设置

1. 启动程序后，点击左下角的齿轮进入“设置”。
2. 可设置预览版、完整版的默认目录，并按需要开启“自动创建作者目录”。保存作者时，程序会在默认目录下使用作者名称建立目录。
3. 在“最小文件大小”中设置导入和同步时忽略的小文件阈值；文件夹不受此限制。
4. 如需同步 Pixiv 小说，在此处粘贴 Cookie，或从 Cookie 文件导入。程序只保存 Pixiv 同步需要的 `PHPSESSID`。
5. “排除标签”用中英文逗号分隔；包含这些文字的 Pixiv 标签不会写入作品记录。
6. 默认抓取策略为作品超过 150 篇时，每篇详情请求间隔 1 秒，可在此处调整。

### 2. 新建作者

1. 在“作者库”点击新增作者，填写名称，也可以填写 Pixiv 作者主页。
2. 填写主页后点击“同步作者信息”，程序会读取作者名称与头像；随后点击“保存作者”才会保存信息与目录设置。
3. 为作者设置预览版文件夹、完整版文件夹和“关联相似度”。相似度用于将不同但近似的文件名识别为同一作品。

### 3. 导入作品名称

进入某位作者后，点击“导入作品名称”。支持以下来源：

- 粘贴文本：可设置固定开头，仅导入匹配行；若名称以日期开头，会自动提取发布日期，其余部分作为作品名称。
- Excel/CSV：选择包含作品名称的一列，未选择时默认第一列。
- 文件夹：导入第一层中的 TXT 文件名和文件夹名。TXT 小于最小文件大小时会跳过，文件夹始终保留。

导入前会显示新增、重复和跳过数量。确认后可选择跳过重复记录，或覆盖已有记录。

### 4. 关联预览版与完整版

在作者设置中先指定文件夹，然后在作者作品库使用以下功能：

- **关联预览版文件**：扫描预览版文件夹第一层。未关联的已有作品会自动关联；尚未存在于作品库的预览文件会新增为作品并自动关联。
- **关联完整版文件**：扫描完整版文件夹第一层，按文件名和关联相似度绑定完整版。文件扩展名不影响匹配。
- **单篇手动关联**：右键作品卡，选择关联具体文件。右键菜单还可删除作品、编辑标签、加入或退出系列。
- **批量设置为完整版**：勾选作品后，将其预览版复制到完整版文件夹并自动绑定。

作品卡右上角图标表示是否有完整版和是否收藏。点击没有完整版的作品时，程序会打开预览版；点击有完整版的作品时，优先打开完整版。

### 5. 浏览、搜索与批量管理

- 可按预览版/完整版状态、收藏、发布日期排序与筛选。
- 搜索框可通过下拉框切换为搜索作品名称或标签。
- “所有作品”显示全部作者的作品，仅用于搜索、筛选和查看。
- 批量模式支持全选、批量删除和批量设置为完整版。所有删除操作都会二次确认。
- 作品卡标题下会显示标签和所属系列；标签可在右键后的标签编辑页中逐个删除或通过输入框回车新增。

### 6. 系列作品

点击“系列作品”可查看当前作者的系列卡片；进入系列后会按 Pixiv 系列序号显示作品。右键作品卡可加入已有系列、退出系列，或修改已有的系列序号。同一系列内不能使用重复序号。

### 7. 同步 Pixiv 小说

1. 先在设置中保存有效的 Pixiv Cookie，并在作者设置中填写 Pixiv 作者主页和预览版文件夹。
2. 在作者作品库点击“同步作品”。
3. 填写开始、结束日期时，程序按 Pixiv 原始投稿日期筛选；两个日期留空时，只检查上次成功同步之后的新投稿。
4. 同步会下载小说正文、封面、标签和系列信息到预览版文件夹，并优先按 Pixiv 小说 ID、再按标题相似度跳过已有作品。
5. 同步过程会显示进度，可点击“终止同步”。只有未终止且没有失败作品的同步才会更新“上次成功同步”时间。

### 8. 备份与迁移

在“设置”中可导出或恢复数据库备份。便携版的实际数据位于 exe 同级的 `data` 文件夹；迁移到另一台电脑时，应一并备份该目录以及预览版、完整版的文件目录。

## 开发环境

- Windows 11
- Node.js 20 或更新版本
- Rust stable（MSVC 工具链）
- Microsoft Edge WebView2 Runtime（Windows 11 通常已安装）

## 安装与运行

```powershell
npm install
npm run tauri dev
```

## 构建免安装程序

```powershell
npm run tauri -- build --no-bundle
```

生成文件位于 `src-tauri/target/release/collection-library.exe`。发布前可将其复制并重命名为产品名称。

## 数据与隐私

- Pixiv Cookie、作者数据和本地作品路径仅保存在本机 SQLite 数据库，不应提交到 Git。
- `.gitignore` 已排除构建缓存、依赖、数据库、发布文件和本地调试产物。
- 发布版 `v0.3.11` 使用 Tauri + WebView2；正常 Windows 11 环境可直接运行。
